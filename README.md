# Keysounds

A program that plays sounds of your choice as you type.

## Installation

Clone the repo:

```
git clone https://github.com/lite1pal/keysounds.git
```

## Usage

Run the program:

```
cd keysounds
go run main.go
```

By default, there is an open-source "Rain drops" sound pack included under `/sound`.

You can download any sound pack from [here](https://mechvibes.com/sound-packs?license=Personal+use).

Enjoy!
